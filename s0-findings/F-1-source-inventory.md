### e-Gov の `law_type` と設計書 Authority Class の対応

実測した `law_type` は次の6種のみである。

| e-Gov `law_type` | 設計書 §5.2 Authority Class |
|---|---|
| `Constitution` | （対象外） |
| `Act` | `PRIMARY_LAW` |
| `CabinetOrder` | `CABINET_ORDER` |
| `ImperialOrder` | （対象外・旧勅令） |
| `MinisterialOrdinance` | `MINISTERIAL_ORDINANCE` |
| `Rule` | `MINISTERIAL_ORDINANCE`（府省の規則） |

### Consolidation State

e-Gov が提供するのは各施行日時点の**溶け込み済み現行全文**である。したがって国法令の `consolidation_state` は次で確定する。

```
consolidation_state = OFFICIAL_CONSOLIDATED
verification_status = MECHANICAL（取得時のハッシュ検証まで）
```

自製統合（`DERIVED_CONSOLIDATED`）は国法令では発生しない。設計書 §5.4 の人手確認コストは、国法令には掛からない。

## 2. 告示（未確定・S0 最大のリスク）

### 決定的な事実: **告示は e-Gov に収録されていない**

実測により確認した。

- `law_type` に告示に相当する種別が存在しない（上記6種のみ）
- 法令名に「告示」を含むものは 9,536 件中 **1 件**のみで、それは「告示に関する省令」であり告示そのものではない

**建築実務で判断に直結する告示（例: 平成12年建設省告示第1400号など）は、e-Gov からは一切取得できない。** 国土交通省のサイト等から個別に取得する必要がある。

これが設計書 §15.2 が「Corpus Feasibility を先行させる」とした理由そのものであり、O-1（告示の入手可否）の核心である。

### 調査が必要な事項

| # | 内容 | 対応する項目 |
|---|---|---|
| 1 | 国土交通省の告示掲載ページの構造と網羅性 | F-3 |
| 2 | 対象テーマ（防火・避難）で必要な告示の特定と件数 | F-3 |
| 3 | 掲載形式（HTML / テキストPDF / 画像PDF）の分布 | F-3 |
| 4 | 溶け込み済み現行全文が公式に存在するか | **F-4（最重要）** |
| 5 | 存在しない場合の自製統合コスト（1件あたり所要時間） | F-4 |
| 6 | 更新の検知方法（RSS / 一覧ページの差分 / 官報） | F-3 |
| 7 | 再配布・加工の可否 | F-8 |

### 引き継いだ未検証情報

調査記録（`docs/research-log.md`）に次の記載があるが、**一次情報での再確認が必要**である。設計書 §16 にも未検証として明記されている。

> 国土交通省の告示・通達一覧は、全件を網羅しておらず、最新情報が未掲載の場合があり、官報掲載内容との相違時は官報が優先すると明記している。

この記載が現在も正しいかを F-3 で確認する。正しい場合、`verification_status` に `GAZETTE_VERIFIED`（官報照合済）を設ける設計書 §5.2 の判断が正当化される。
