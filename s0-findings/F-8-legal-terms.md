# F-8: 利用条件の法的確認 — 結果

- 実施日: 2026-07-29
- 目的: e-Gov データ、告示 PDF、自治体例規の再配布・加工条件を一次情報で確認する
- 判定: **確認完了。3 ソースすべて一次情報で確認。リスクは自治体例規に集中**

---

## 1. e-Gov 法令データ（法・令・規則）— 再配布・加工ともに可能

### 適用規約

**公共データ利用規約（第1.0版）= PDL1.0** が適用される。

- 一次情報: e-Gov 法令検索「利用規約」https://laws.e-gov.go.jp/terms/
- 規約本体: https://www.digital.go.jp/resources/open_data/public_data_license_v1.0

### PDL1.0 の要点（実測・一次情報から引用）

| 項目 | 内容 |
|---|---|
| 商用利用 | **可能**（「商用利用も可能です」の明文あり） |
| 複製・公衆送信・翻案 | **自由**（「複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます」） |
| CC BY 互換 | **CC BY 4.0 と互換性がある**（規約1.7に明記） |
| 出典明示 | **義務**（「出典を記載してください」） |
| 加工の明示 | **義務**（「編集・加工等を行ったことを記載してください」。国が作成したかのような誤認を与える表示は禁止） |
| 第三者権利 | 利用者の責任で確認（写真・図版等の肖像権・著作権） |
| 免責 | 予告なく変更・削除されることがある。提供者は責任を負わない |
| 準拠法 | 日本法 |

### BLRA への含意

e-Gov の法令データ（建築基準法・施行令・施行規則）をサービスに組み込み、再配布・加工することは**PDL1.0 の範囲で自由に可能**。以下の実装要件を満たす必要がある。

1. **出典明示**: 「出典：e-Gov 法令検索（https://laws.e-gov.go.jp）」を表示
2. **加工の明示**: 本サービスが構造化・セグメント化したことを明示
3. **取得メタデータの保持**: 取得日、法令ID、版、施行時点（設計書 §5 の SourceVersion モデルが要件を満たす）
4. **規約変更の監視**: PDL1.0 は「今後変更される可能性があります」と明記。定期監視の仕組みが必要

**リスク: 低。** ただし「予告ない変更・削除」があるため、Content Hash による差分検知（設計書 §8.1）は必須。

## 2. 国土交通省の告示 PDF — 再配布・加工ともに可能

### 適用規約

**PDL1.0 に準拠**（e-Gov と同一）。

- 一次情報: 国土交通省「リンク・著作権・免責事項」https://www.mlit.go.jp/link.html

### 実測の要点

> 「国土交通省ウェブサイトで掲載・発信している情報の著作権は、特記されていない限り国土交通省に帰属し、権利表記の記載がない限り『公共データ利用規約（第1.0版）』に準拠した利用条件の下で、利用することができます。」

告示 PDF は「特記」がない限り PDL1.0 の対象である。確認した限り、建築基準法関係告示の掲載ページに個別の利用制限の記載はない。

### 注意事項（一次情報に明記あり）

1. **個別法令による制約**: 測量法に基づく測量成果等、一部コンテンツは個別法令で利用制限がある。告示本文には該当しないが、告示に添付される地図・図面が該当する可能性がある
2. **シンボルマーク・ロゴ**: PDL1.0 の適用外。バナー画像の転用は不可
3. **予告なしの変更・削除**: 「予告なしに内容を変更又は削除する場合があります」。F-3/F-4 で実測した「同じ URL の PDF が差し替わる」事象と一致

### BLRA への含意

告示 PDF を取得・構造化・再配布することは PDL1.0 の範囲で可能。e-Gov と同一の出典明示・加工明示の要件が適用される。

**ADR-023（案B）との整合**: 案文（`OFFICIAL_AS_ENACTED`）と改正履歴を提示するだけであれば、加工度は低く、PDL1.0 の要件は容易に満たせる。

**リスク: 低〜中。** 中なのは、告示に添付される図面・地図の第三者権利・個別法令制約を個別に確認する必要があるため。

## 3. 自治体例規 — **ここにリスクが集中する**

### 3.1 法令そのもの（条例・規則の条文）は著作権の対象外

**著作権法第13条** により、条例・規則・告示は著作権の対象とならない。

- 憲法その他の法令（法律、政令、省令、**条例や規則**を含む）
- 国や地方公共団体等の**告示・訓令・通達**
- 裁判の書類
- 上記の翻訳・編集で公的機関が作成したもの

**条文そのものの再配布・加工には著作権上の制約はない。** これは文化庁の著作権テキストおよび多数の法律事務所の解説で一致している。

### 3.2 問題は「サイトの編集著作物」と「運用資料」

#### 東京都の実測（重要な差異）

東京都は **PDL1.0 を採用していない**。

- 一次情報: 東京都「著作権・リンクについて」https://www.metro.tokyo.lg.jp/policy/chosakuken

> 「当サイトに掲載されている文章、イラスト、ロゴ、写真、動画、ソフトウェア、その他すべての情報は、著作権の対象となっています。また、東京都公式ホームページ全体も**編集著作物として著作権の対象**となっており、ともに著作権法により保護されています。『私的使用のための複製』や『引用』など著作権法上認められた場合を除き、**無断で複製・転用することはできません**。」

これは e-Gov・国交省（PDL1.0 で自由利用を認める）とは**対極の姿勢**である。

ただし、条例・規則の条文自体は著作権法第13条で権利の目的とならないため、**条文の複製・加工は著作権法上認められている**。東京都の表示は、条文ではなく「ページ全体の編集著作物」「レイアウト」「索引」「解説」等を保護対象としていると解される。

#### 自治体ごとに利用条件が異なる

調査記録 §31.2 の記載を一次情報で裏付けた。自治体により次の3パターンが存在する。

| パターン | 利用条件 | BLRA での扱い |
|---|---|---|
| **A. PDL1.0 採用** | 自由利用・出典明示 | 条文の全文収録が可能 |
| **B. 独自規約（東京都型）** | 条文は第13条で自由だが、編集物は要許諾 | 条文のみ収録。レイアウト・索引は独自構築 |
| **C. 利用条件不明・有償掲載の連絡義務** | 個別確認が必要 | リンク・メタデータのみ保持（調査記録 §31.2 の方式B） |

### BLRA への含意

**自治体例規は一律スクレイピング・再配布ではなく、3方式を使い分ける（調査記録 §31.2 の方針を一次情報で裏付け）。**

1. **条文そのもの**: 著作権法第13条により自由に再配布・加工可能（いずれの自治体でも）
2. **編集構造（目次・索引・関連条文リンク）**: 自治体の利用条件に依存。独自構築が安全
3. **運用基準・取扱基準・FAQ**: 条文ではない場合があり、個別の権利確認が必要。横浜市の取扱基準集は「有償掲載の場合は連絡を求めている」

設計書 §15.8.3 の「自治体条例はパーサを書かず手動登録」の方針は、この利用条件の複雑さを回避する意味でも正しい。手動登録であれば、各文書の利用条件を登録時に確認・記録できる。

**リスク: 中〜高。** 自治体ごとに条件が異なり、 Design Partner の自治体（O-4）が確定するまで個別確認できない。

## 5. BLRA が満たすべき実装要件

F-8 の結果として、次を設計・実装要件に組み込む。いずれも設計書 §5 の SourceVersion モデルで表現可能であり、スキーマの追加は不要。

1. **出典明示の自動生成**: 各 SourceVersion に `source_url` と `license_notice`（出典記載例）を持たせる
2. **加工明示の表示**: 本サービスが構造化したことを利用者画面に表示する
3. **license_class の属性化**: SourceVersion に利用規約の種別（PDL1.0 / 独自規約 / 不明）を持たせる
4. **Content Hash による差分検知**: 「予告ない変更・削除」に対応（設計書 §8.1 で既に要件化）
5. **規約変更の定期監視**: PDL1.0 の改訂と、自治体規約の変更をポーリングで検知する
6. **自治体資料の3方式使い分け**: 手動登録時に利用条件を確認し、license_class に記録する

## 6. 設計書との整合

- 設計書 §5.2 の `verification_status`（`GAZETTE_VERIFIED` / `MECHANICAL`）は、利用規約ではなく真正性の軸である。利用規約は別の属性として持つ
- 調査記録 §31 の記載は、一次情報で概ね裏付けられた。唯一の修正点は「東京都が PDL1.0 を採用していない」の実測（調査記録では東京都例規を「オープンデータ条件が明確な HTML 例規」としていたが、東京都サイト全体は PDL1.0 ではなく独自規約である）
- O-5（再配布条件）は本結果をもって**確認完了**とする。ただし自治体ごとの個別確認は O-4（対象自治体確定）後に必要
