## 1. 本法令集の特色について（誌面転記）

1. 主として「建築士試験受験者」および「建築実務者」向けに編纂された建築系法令集。法令告示の横書き化、厳選した収録法令、簡潔な傍注、2色刷り印刷の採用により、より読みやすく、より引きやすく、よりコンパクトな法令集を目指した
2. 2026年版（令和8年版）は、**令和7年9月30日**までに公布された法令を収録
3. 各法令は、**令和8年1月1日現在において施行されている**内容とした
4. 各法令の最終改正の年月日は、本文中の改正の有無にかかわらず改正法令の公布年月日とした
5. 収録条文は、建築基準法・同施行令、建築士法・同施行令、都市計画法・同施行令の6法令について**本則全文収録**、その他は**抄録**
6. 法令本文は横書き化に伴い、原則として漢数字（諸数値）を算用数字、単位名称を記号で表記。指示語は「上欄→左欄」「左の→次の」等に変更。条文中の二重かっこの二重目を〔　〕とした
7. 傍注・編注・索引等は、法令名・表題名を一部簡略化した簡易表記
8. 条文に見出しや項番号をもたない法令（消防法など）は、適宜見出しを〔　〕で付し、項番号を付した
9. **傍注は検索性を高めるため、本書収録の関係法令・関係条文を記載し、➡記号と算用数字で該当頁を記載。** 本書に収録していない法令・関係条文も一部記載
10. 本則全文収録の6法令は、傍注を本文の右側に掲載

## 2. 表記方法一覧

### 2.1 漢数字の算用数字化

「漢数字」（諸数値）を「算用数字」で表記する。ただし**第一種・一級といった「区分」、法令中の「号」等を除く**。

- 万・億以上の桁は文字と併用し位取りする（法令告示等の「番号」を除く）。例: 一万五千 → 1万5,000 ／ 一億八千万 → 1億8,000万
- 割合は分数。例: 十分の七 → 7/10

### 2.2 単位名称記号

```
ミリメートル→mm   センチメートル→cm   メートル→m    キロメートル→km
平方ミリメートル→mm²  平方センチメートル→cm²  平方メートル→m²
立方センチメートル→cm³  立方メートル→m³
ミリグラム→mg  グラム→g  キログラム→kg  ヘクタール→ha
パーセント→%  キロワット→kW  メガワット→MW  ケルビン→K
キロジュール→kJ  メガジュール→MJ  ギガジュール→GJ
```

複合単位の例: 一平方メートルにつきニュートン→ニュートン/m²、一秒間につきメートル→m/秒、一分メートルにつき人→人/分m、一時間につきキロカロリー→キロカロリー/時間、一キログラムケルビンにつきキロジュール→kJ/kgK、一リットルにつきミリグラム→mg/リットル

### 2.3 指示語の表記

「上欄→左欄」「下欄→右欄」「左の→次の」「右の→上の」「上段→左列」

### 2.4 傍注での法令引用の略記 ★Citation Resolver に直結

法律・施行令（政令）・施行規則（省令）を「法」「令」「規則」と表記。一部法令は略称を併用。建設省告示・国土交通省告示（平成13年1月6日以降公布分）を「告示」と表記。**原則として「第」を省略し、一部、算用数字を併用。**

```
建築基準法第二条                    → 法2条
建築基準法施行規則第四条の二十第二項  → 規則4条の20第2項
都市計画法第八条第一項第四号の二      → 都計法8条1項四号の二
平成十二年建設省告示第千三百九十九号  → 平12告示1399号
```

### 2.5 傍注のアイコン

`政`→政令 ／ `省`→省令 ／ `府`→府令 ／ `告`→告示 ／ `関`→関連

## 4. BLRA への示唆

### 示唆1: 紙の法令集は「固定時点のスナップショット」である

特色③が「**令和8年1月1日現在において施行されている**内容」と明記している。収録は令和7年9月30日公布分まで。

つまり紙の法令集は、**1年に1冊、ある1時点だけを切り取ったもの**である。BLRA の時点指定（§4）は、この構造的制約を直接置き換える機能にあたる。差別化として明確である。

同時に、未施行改正を扱えないことも意味する。F-5 で建築基準法に未施行版が3件実在することを確認しており、紙では追えない。

### 示唆2: 傍注は Reference Edge の手作業版である

特色⑨が「傍注は検索性を高めるため、関係法令・関係条文を記載し、➡記号と算用数字で該当頁を記載」と述べている。実際の誌面でも次の形で現れる。

```
第234条　建物を築造するには、境界線から50cm以上の距離を保たなければならない。
　関 隣地境界線に接する外壁＝建基法63条➡74
```

**これは設計書 §7 の Reference Edge を、人手で構築して紙面に埋め込んだものである。** BLRA が自動抽出しようとしているものが、既に商品として成立していることの証左になる。

差別化の所在も明確になる。紙は片方向（頁番号への参照）で、逆引き（この条文を参照している条文の一覧）ができない。BLRA の `references` API は双方向を返せる（§12.2）。

### 示唆3: 引用の略記パターンが Citation Resolver の仕様に直結する

特色⑦と表記方法(1)が示す略記は、F-6 の Citation Resolver が扱うべき入力そのものである。

```
法2条 / 規則4条の20第2項 / 都計法8条1項四号の二 / 平12告示1399号
```

**未対応のパターンを1つ発見した。** 「都計法8条1項**四号の二**」は、号に枝番が付いている。現在の `EXPLICIT_RE` は `第(NUM)号` までしか見ておらず、`号の二` を取りこぼす。しかも**号は漢数字のまま**である（表記方法(1)が「区分、法令中の『号』等を除く」と明記）。

→ F-6 の残課題へ追加する。

### 示唆4: 商業法令集ですら告示は「抜粋」である

建築基準法関係告示は1276〜1605頁（約330頁）を占めるが、表題は**「抜粋」**である。

ADR-023（案B）の判断を補強する。**専門の出版社が編集リソースを投じても、告示は全件収録していない。** 告示の網羅は、当プロジェクト固有の困難ではなく、この分野の構造的な困難である。

### 示唆5: 老人ホーム関連法令が収録されている（ADR-026 に影響）

ADR-026 は消防法・老人福祉法を「別法令のため MVP 範囲外」とした。しかし商業法令集は次を収録している。

