# ADR-026: 対象テーマの確定（O-3）

- ステータス: Accepted
- 決定日: 2026-07-29
- 対応する未解決事項: O-3（設計書 §16）
- 関連: ADR-023（案B）、ADR-025（Domain Review 体制）、F-9（遡及範囲）

## 決定

MVP の対象テーマを次に確定する。

> **就寝用途のある福祉施設（老人ホーム等）の、新築における防火・避難**

設計書 §2.3 の第一候補「防火・避難」を維持したうえで、用途と場面を絞り込んだ。

## 根拠

### 1. 実装者の実務領域と一致する

ADR-025 のとおり、実装者は二級建築士で、主に老人ホーム規模の設計実務に従事していた。

これは対象テーマの選定において決定的な利点をもたらす。**正解セットを外部の助けなしに作れる。**

設計書 §9.5 は Search Evaluation Harness の正解セットを Recall@10 の判定基準としており、F-6 の findings は「正解セット1〜2件の誤りで判定が反転しうる」と警告している。正解セットの品質がそのまま Pilot の合否判定の品質になる。実務経験のある領域を選べば、ここが自力で担保できる。

同じ理由で、U-2 の Baseline タスク設計、参照関係の妥当性判断、告示と法令の対応付けの検証も自力で回せる。

### 2. 法令構造が防火・避難の中核に直結している

実コーパス（建築基準法・施行令・施行規則、6,552 条項）を検索して確認した。

老人ホームは次の連鎖で用途判定される。

```
令19条          児童福祉施設等の定義（老人ホームを含む）
   ↓
令115条の3第一号  別表第一(い)欄(二)項に「類するもの」として児童福祉施設等を指定
   ↓
法27条 / 法35条   特殊建築物としての耐火・避難の規定が掛かる
```

そのうえで、老人ホームが直接名指しで現れる条項が防火・避難の中核に分布している。

| 条項 | 内容 |
|---|---|
| 令112条12項・13項 | 防火区画（竪穴区画・異種用途区画） |
| 令114条2項 | 界壁 |
| 令121条1項四号・4項 | 二以上の直通階段 |
| 令110条の4 | 警報設備に関する規定 |

関連条文群の規模も MVP に適している。令112条系 46 条項、令123条（避難階段）25 条項、令126条の2・3（排煙）23 条項、令114条 10 条項。**Solo Track のコーパス規模（告示 15〜20 件）に収まる。**

### 3. 判断が難しく、間違えると重い

就寝用途かつ自力避難困難者を収容するため、避難規定が最も厳しく掛かる用途のひとつである。誤ると人命に直結し、実務者の確認負荷も高い。設計書 §1.2 の提供価値（見落としを減らす）が効く領域である。

### 4. 新築に限定する理由

F-9 で判明したとおり、条文の遡及は建築基準法で 2016-09-01、施行令・規則で 2017-04-01 までである。既存不適格（法3条2項）が問題になる案件では、当該時点の条文を表示できない。

コーパス検索でも、老人ホームは令137条の8・137条の18・137条の19（既存不適格建築物への制限緩和）に現れる。**用途変更や増改築を対象に含めると、F-9 の制約に正面から当たる。**

したがって MVP は新築に限定する。用途変更・既存不適格は Pilot 後の拡張候補とし、その際に F-9 の代替ソース（官報アーカイブ等）の検討を再開する。

## この決定で扱わないもの

| 範囲外 | 理由 |
|---|---|
| 消防法の規定 | 別法令。設計書 §2.2 のコーパス範囲外。実務では併せて確認するが、MVP では扱わない |
| 介護保険法・老人福祉法の設備基準 | 同上 |
| 用途変更・既存不適格 | F-9 の制約（上記） |
| 老人ホーム以外の特殊建築物 | Pilot 後に段階拡張。ただし別表第一(二)項の他用途（共同住宅・ホテル等）は構造が近く、拡張しやすい |

## リスク

### 市場性は未検証である

**この決定は実装の確実性を優先したものであり、市場規模の検証に基づいていない。**

対象テーマを実装者の得意領域に寄せることで、正解セットの精度と開発速度は上がる。一方で「高齢者施設を手がける設計事務所が、この規模の課題に対価を払うか」は分かっていない。

U-1 の実務者接点は、この用途を扱う設計事務所から確保することが望ましい。**テーマを絞った結果、U-1 の対象も絞られる**点は認識しておく。

### 拡張の道は残す

別表第一(い)欄(二)項の他用途（共同住宅、ホテル、旅館、病院、寄宿舎）は、令115条の3を介した同じ用途判定構造を共有する。老人ホームで成立したモデルは、これらへ比較的低コストで広げられる。**袋小路ではない。**

## 副産物: 実務語と法令語のギャップを再確認

コーパス検索で **「就寝」は 0 件**であった。実務では「就寝用途」と呼ぶが、法令本文にこの語は現れず、別表第一と令115条の3による用途指定で表現されている。

F-7 で確認した「無窓居室」（法令表記は「窓その他の開口部を有しない居室」）に続く2例目である。設計書 §9.3 の同義語辞書が必須機能であることを、さらに裏付ける。

初期エントリへ追加する。

| 実務語 | 法令上の表現 |
|---|---|
| 無窓居室 | 窓その他の開口部を有しない居室 |
| 就寝用途 | 別表第一(い)欄(二)項＋令115条の3第一号による用途指定 |
| 老人ホーム | 児童福祉施設等（令19条）に含まれる |
