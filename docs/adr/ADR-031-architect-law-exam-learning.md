# ADR-031: 一級建築士法規過去問による要件学習への切替

- ステータス: Accepted
- 決定日: 2026-08-09
- 決定者: Taguchi
- 関連: 設計書 §15.3 / §15.8.3 / §15.9、ADR-024、ADR-025、`user-research/`

## 背景

従来の U-1/U-2 は、最低5名・2組織の実務者を集め、インタビューと法令調査の所要時間を
計測する計画だった。この方法は外部参加者の確保が開発ゲートになり、Solo Track の継続的な
要件学習・回帰評価として再現しにくい。

一方、建築技術教育普及センターは、一級建築士試験「学科Ⅲ（法規）」の過去問題と正答肢を
公式に公開している。学科Ⅲは毎年30問で、建築基準法の定義・手続・防火避難・構造・集団規定に
加え、建築士法、都市計画法、消防法、バリアフリー法、建築物省エネ法、複数法令を横断する
設計者判断を含む。

令和3〜7年の150問を初回棚卸ししたところ、132問が数値・案件条件、67問が例外・緩和等を含み、
条文番号を明示するものは24問だった。BLRA が支援すべき中心課題は、条番号入力ではなく、
案件条件から本則・委任先・例外へ到達することだと判断できる。

## 決定

### 1. 外部参加者調査を開発ゲートから外す

最低5名・2組織、90分セッション、画面録画、所要時間中央値を U-1/U-2 の完了条件にしない。
実務者の有償利用意思や組織内ワークフローは、動く製品ができた後の任意フィードバックとする。

### 2. 公式過去問150問を要件学習の一次資料にする

- 学習セット: 令和3〜6年、120問
- 未見評価セット: 令和7年、30問
- 正答: 各年度の公式「合格基準点等」に掲載された正答肢
- 更新: 新年度問題を未見評価へ追加し、前年を学習セットへ移動

### 3. 問題文を転載せず派生情報だけを保持する

年度、問題番号、適用法令日、課題分類、案件条件、短い検索語、根拠条文セット、法令間経路、
例外、未収録資料、公式正答肢、根拠確認状態を保持する。問題文・選択肢の全文は保存しない。

過去問は試験実施時点の法令に基づくため、現在の法令へ自動的に読み替えない。

### 4. 所要時間指標を根拠到達指標へ置き換える

旧 North Star「Baseline 比の時間短縮」は使わない。Recall@10、根拠条文セット到達率、
法令間経路完全率、例外確認率、未収録明示率、誤根拠率を主要指標とする。

## 置き換える決定

- ADR-024 の「U-1 完了を S1 着手の実質的前提とする」判断を撤回する
- ADR-025 の「案B の成否は U-1 でしか確かめられない」という開発ゲート判断を撤回する
- 設計書 §15.3、§15.8.3、§15.9 の参加者数・組織数・所要時間 Baseline を本 ADR で置き換える
- 旧 U-1 インタビューガイドと U-2 Baseline プロトコルは履歴参照用とする

## 帰結

- U-1/U-2 は外部調整なしで反復可能になる
- Search Evaluation Harness と関連ナビの正解セットを同じ一次資料から作れる
- 条件検索、法令横断、例外、未収録表示を毎年回帰評価できる
- 有償性、組織内引き継ぎ、自治体固有運用はこの方法では検証できないが、S1/S2 の前提にしない

実施手順は `user-research/architect-law-exam-protocol.md` を正本とする。

## 2026-08-09 補足決定: 複合問題の扱い

正答肢の主要論点だけでは、複数法令・複数条文をまたいで問題全体を解く能力を評価できない。
各問題は、全選択肢から派生する論点と問題全体の統合判断を持つ階層型データとして扱う。

- 問題文・選択肢の全文は保存せず、対応は選択肢番号だけで保持する
- 各派生論点に案件条件、短い判断課題、期待する結論、根拠条文、複数の到達経路、例外、
  未収録資料、確認状態を持たせる
- 計算問題等では一つの論点で複数の選択肢番号をカバーしてよい
- 全選択肢、全論点、統合判断、適用法令日を確認した問題だけを問題単位の評価対象にする
- 令和3年30問の現行下書きは正答主要論点だけの部分データとして扱い、自動的に完成扱いしない
