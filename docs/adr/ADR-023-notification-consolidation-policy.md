# ADR-023: 告示の溶け込み現行全文を提供せず、原文＋改正履歴の提示に留める

- ステータス: Accepted
- 決定日: 2026-07-29
- 決定者: Taguchi（事業判断）
- 関連: 設計書 §5.2 / §5.3 / §15.2 / ADR-009 / ADR-014 / ADR-017
- 実測根拠: s0-findings/F-3-F-4-notifications.md

## 背景

設計書 §15.2 は Corpus Feasibility（S0）を User Research に先行させる独立ゲートとし、
告示の溶け込み済み現行全文が公式に入手できない場合に 3 つの事業判断肢（案A/B/C）を提示していた。

S0 の F-3 / F-4 実測の結果、次が確定した。

1. 告示は e-Gov に収録されていない（実測。`law_type` 6 種に告示は含まれない）。
2. 国土交通省の告示掲載ページは PDF 形式であるが**テキストPDF であり OCR は不要**（F-3 の追い風）。
3. ただし公式に掲載されるのは**案文（制定時本文）と新旧対照表のみ**。
   `OFFICIAL_CONSOLIDATED`（溶け込み済み現行全文）に相当するものは存在しない（F-4）。
4. 1 つの改正告示が 34 件以上の既存告示を同時に改正する実例がある。
   自製統合は S0 中止条件（1件あたり 2 時間）を超える見込み（F-4）。
5. 公式掲載物にも誤りがあり、後から差し替わり、官報が優先する（§5.2 `GAZETTE_VERIFIED` の正当性を実証）。

## 決定

**案 B を採用する。** 告示の溶け込み済み現行全文は提供しない。

告示の取扱いは次の形とする。

1. 告示の**案文（制定時本文）を `OFFICIAL_AS_ENACTED` として収録する**。
2. その告示に掛かるすべての改正を、**改正履歴の一覧として時系列で提示する**（新旧対照表へのリンク付き）。
3. UI 上で「この告示には公布後 N 件の改正があります。現行全文は本サービスでは提供していません」と明示する。
4. `DERIVED_CONSOLIDATED`（機械統合した編集現行版）は MVP では作成しない。

需要が U-1（実務者ヒアリング）で確認できた特定の告示についてのみ、
S1 以降に人手確認込みで限定適用する可能性を残すが、これは別途 ADR を起す条件とする。

## 棄却した代替案

- **案 A（自製の編集現行版を提供）**: 価値は最大だが、Solo Track の工数を確実に超え、
  Domain Reviewer の確認工数も跳ね上がる。S0 中止条件を満たさないため棄却。
- **案 C（対象テーマを告示依存の少ない領域へ変更）**: 防火・避難は告示依存が最も強い領域であり、
  テーマ変更の効果は大きいが、調査頻度の高さという当初の選定理由を失う。本 ADR では採用しない。
  なお O-3（対象テーマの確定）は別議論であり、F-9 の結果（既存不適格の時点参照制約）と合わせて S0 Exit で決定する。

## 設計への影響

本決定は設計書と矛盾しない。むしろ既存の制約がそのまま活きる。

- §5.2 の Consolidation State モデルは変更不要。
  告示は `OFFICIAL_AS_ENACTED` / `OFFICIAL_AMENDMENT` を取る。
- §5.3 制約 2（`DERIVED_CONSOLIDATED` は Primary Citation に入れられない）は、
  案B では `DERIVED_CONSOLIDATED` をそもそも作らないため、より強い形で満たされる。
- §5.4 の Publish 判断（HUMAN_REVIEWED 昇格を必須）は、限定適用を行う場合の関門としてそのまま適用する。
- §18 の最重要原則（誤った条文を自信を持って表示しない）と完全に整合する。

## 残るリスクと確認事項

- **価値提案の後退**: 「紙の法令集の代替」という当初の期待には応えられない。
  U-1（実務者ヒアリング）で**「告示の現行全文が読めないツールに価値があるか」を必ず確認する**。
  これが案B 採用時の価値提案の成否を分ける唯一の論点である。
  ヒアリング結果が芳しくない場合は、案 A の限定適用または案 C への再考を ADR 改訂として起す。
- F-3 の本検証（対象テーマの告示 50 件で 45 件以上の出典取得）は継続して実施する。
  案B であっても、案文の収録と改正履歴の網羅には F-3 の合格が前提である。
