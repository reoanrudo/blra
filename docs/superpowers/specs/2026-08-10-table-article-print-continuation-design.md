# 表を含む条文印刷の設計

## 目的

表の上から右クリックしても、表だけを切り離さず、その表を含む条文全体を印刷できるようにする。長い表は紙面内に無理に縮めたり途中で捨てたりせず、次の紙ページへ連続して出力する。

## 操作

- 条文・段落・表セルのいずれを右クリックしても、通常の条文メニューの先頭に `🖨 この条を印刷` を表示する。
- 表専用の印刷項目は設けない。表上の操作も同じ `この条を印刷` へ統一する。
- これにより、表題、表、表の前後にある条文、備考を同じ印刷対象として出力する。
- テキスト選択、条文リンク、既存ハイライト上の右クリックは、従来の専用メニューを優先し、条印刷項目を表示しない。

## 印刷レイアウト

- 対象の条以外、編・章・節見出し、操作 UI は印刷時に隠す。
- 表は幅を印刷可能領域へ収め、通常のページ分割を許可する。表の高さを固定せず、途中で切り捨てない。
- 表の行は可能な限り同じ紙ページ内に保つ。ただし行自体が紙面より長い場合は、ブラウザの標準ページ分割に委ねる。
- 表が複数ページへ続く場合、先頭行を各ページの見出しとして繰り返し、次ページ以降にも列の意味が分かるようにする。
- 印刷終了後は、通常の全文表示に必ず復帰する。

## 実装設計

1. `TableBlock` の表に印刷用の `thead` と `tbody` を持たせ、先頭行をヘッダーセルとして描画する。
2. 印刷 CSS では `thead` を `table-header-group`、`tr` を `break-inside: avoid` とし、表・セルを `overflow: visible` にする。
3. 既存の `data-print-current` による条単位の範囲絞り込みをそのまま利用する。表の祖先から条ルートを解決する現在の右クリック処理は維持する。
4. 印刷前だけに適用する属性は、ブラウザの印刷終了イベントでも除去し、通常画面に残さない。

## 検証

- 表セルを右クリックしたとき、`この条を印刷` が表示されること。
- 印刷媒体では、対象条の前後の条文、表、備考が表示され、他の条は非表示になること。
- 印刷媒体で表のヘッダー行が `table-header-group` となり、行がページ途中で分断されにくいこと。
- 通常の画面表示と、ハイライト・リンク・選択時のメニュー優先順に回帰がないこと。
