# 施行令・施行規則の表を別表基準へ統一する設計

## 目的

建築基準法の別表で用いている落ち着いた法令集形式の表組を、建築基準法施行令・建築基準法施行規則の表へ適用する。表の内容、結合セル、数値表記は変更しない。

## 適用範囲

- 法令名が「建築基準法施行令」または「建築基準法施行規則」である表。
- 対象は本文中の表と別表の両方。
- 建築基準法の別表は現在の旧レイアウトを維持する。
- 上記以外の法令の表は現行レイアウトを維持する。

## 表示ルール

- 背景色・強調色を使わない。
- ヘッダーを含む罫線は同一の色・太さにする。
- セル余白、文字サイズ、改行・折り返し、短い記号セルの中央配置は建築基準法の別表と同じ規則にする。
- 列幅は内容量と結合セルを考慮して決め、元の表構造を保つ。
- 横スクロールは発生させない。狭い画面ではセルの文字サイズのみ段階的に縮小する。

## 実装方針

表の法令名を基にレイアウト種別を判定する。対象表には既存の旧レイアウト用クラスと列幅計算を適用し、それ以外は現行の自動レイアウトを使う。表構造の補正・表示用数値変換・印刷用の改ページ制御は共通のまま維持する。

## 検証

- 対象2法令の表が背景色なし、均一な罫線、横スクロールなしで表示されること。
- rowspan・colspan・空セル・分数セルが崩れないこと。
- 建築基準法の別表と対象外法令の表が意図せず変わらないこと。
- 型チェックと既存テストを通すこと。
