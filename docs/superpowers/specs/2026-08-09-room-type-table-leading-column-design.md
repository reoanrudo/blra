# 居室の種類表・セル配置補正 設計

## 目的

建築基準法施行令第19条第3項の表を、3列（番号・居室説明・割合）の意味に沿って表示する。元データに欠けている見出しの横結合と割合セルの縦結合を、対象表の描画時だけ補う。

## 表示仕様

- 列0（`(1)`〜`(8)`）は35px固定とする。
- 右端の割合列は70px固定とする。
- 見出し「居室の種類」は列0と居室説明列を横結合する。
- 見出し「居室の種類」は結合セル内で中央揃えにする。
- 見出し「割合」は右端の分数列へ配置する。
- `1/5` は `(1)`〜`(2)` の2行を縦結合する。
- `1/7` は `(3)`〜`(6)` の4行を縦結合する。
- `1/10` は `(7)`〜`(8)` の2行を縦結合する。
- PC・モバイルの両方へ適用する。

## 対象範囲

- 対象法令: 建築基準法施行令
- 対象表: 第19条第3項の最初の表
- 同じ見出しを持つ別条文・別法令の表は変更しない。
- DBおよび取込済み法令データは変更しない。

## 採用設計

法令名と安定ノードキーで対象表を判定する。対象表では、セル表示補正を返す純粋関数によって次の情報を生成する。

- 見出し先頭セル: `colSpan: 2`、`textAlign: center`
- 値のある割合セル: 直後に続く空白割合セル数を含む `rowSpan`
- 空白割合セル: `hidden: true`

レンダラーは全行から最大列数を計算して3列の `colgroup` を生成し、列0へ35pxを設定する。割合列の空白セルは描画せず、直前の分数セルの `rowSpan` で覆う。

## 検討した代替案

1. 対象表だけ描画時に補正する: 影響範囲が限定され、DB再取込も不要なため採用。
2. DBのセルメタデータを更新する: 再取込時に失われ、データ変更の影響も大きいため不採用。
3. 全表で空白セルを自動結合する: 意図的な空欄まで結合する危険があるため不採用。

## 検証

- 純粋関数の単体テストで、35pxと70pxの固定幅、見出し横結合と中央揃え、割合セルの2・4・2行結合、対象外表の無変更を確認する。
- 型検査を実行する。
- 実ブラウザで対象表の列幅、見出し位置、分数セルの `rowspan` を測定する。
