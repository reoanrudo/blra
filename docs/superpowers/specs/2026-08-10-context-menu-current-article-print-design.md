# 条文右クリック印刷の設計

## 目的

閲覧中の法令を全文印刷するのではなく、必要な条だけを印刷できるようにする。印刷操作は本文上の右クリックメニューから明示的に実行し、通常の閲覧画面の操作を増やさない。

## 対象範囲

- 条文、段落、表のセルを右クリックした際の通常の条文メニューに、`🖨 この条を印刷` を追加する。
- 選択中のテキスト、既存ハイライト、条文リンクを右クリックした場合は、現在の各専用メニューをそのまま優先する。
- 通常のヘッダーにある曖昧な `印刷` ボタンは撤去する。
- 全文印刷は既定操作にせず、今回の変更では右クリックメニューにも追加しない。

## 印刷範囲

右クリックした要素が段落、号、表セルなどの子要素であっても、その子要素だけは印刷しない。最も近い条のルート（`data-scroll-article-id` を持つ表示ブロック）を印刷対象として、条見出し・本文・表・備考を含めて出力する。

条の外にある編・章・節などの見出しを右クリックした場合は、印刷項目を表示しない。対象となる条を特定できない場合も、何も印刷せず、既存メニューの挙動を維持する。

## 実装設計

1. 右クリックの発火時に、従来の `data-article-id` だけでなく、対象要素の祖先から印刷対象となる `data-scroll-article-id` を取得する。
2. 条文メニューの最上部に `🖨 この条を印刷` を配置する。キーボード操作の番号とメニュー高さの見積りも新しい項目数に合わせる。
3. 印刷操作では対象表示ブロックに一時的な属性を付け、印刷用 CSS で同じ法令内の他の条・編章見出しを非表示にする。既存の操作 UI 非表示ルールは維持する。
4. `window.print()` を実行した後、`afterprint` で一時属性を必ず除去する。印刷ダイアログを閉じた後に通常表示が変わらないようにする。
5. 印刷対象の条と同じ DOM に含まれる表・備考はそのまま出力する。横スクロールを使わない既存の表レイアウトを印刷時にも維持する。

## ハイライトとの互換性

テキスト選択中の右クリックはハイライト作成メニューを、既存ハイライト上の右クリックは削除・コピーのメニューを引き続き開く。これらの優先順を変更しないため、ハイライトの作成、表示、削除、コピーへの影響はない。

## 検証

- 右クリックした条文メニューに印刷項目が表示され、選択・リンク・既存ハイライトのメニューには表示されないこと。
- 印刷項目でブラウザ標準の印刷が呼ばれること。
- 印刷媒体では対象の条のみ表示され、その条の表と備考は表示され、他の条と操作 UI は非表示になること。
- 印刷終了後に一時属性が残らず、通常画面の全条文表示が復元されること。
