# 法令本文の小数・時間単位・コピー表示統合設計

## 1. 目的

法令本文と表にある漢数字の小数および時間当たりの単位表記を、横書き法令集の表示規則に合わせて読みやすくする。また、通常のコピー操作では公式原文ではなく、画面に表示されている算用数字・単位記号を取得できるようにする。

公式原文は変更しない。既存の原文座標、ハイライト、条文リンク、注釈の内部処理は引き続き公式原文を基準とする。

## 2. 対象範囲

### 2.1 漢数字小数

小数点の前を漢数字の数量、小数点の後を漢数字の各桁として解釈する。

- `二十・五パーセント` → `20.5%`
- `百二十・五` → `120.5`
- `三・〇パーセント` → `3.0%`
- `〇・〇〇五ミリグラム` → `0.005mg`
- `一万二千三百四十五・六七` → `1万2,345.67`

小数点の後は位取り計算をせず、一文字ずつ `0` から `9` へ置換する。これにより先頭および末尾のゼロを保持する。

数値ではない中点は変換しない。

- `A・B` → `A・B`
- 人名、区分名、固有名詞に含まれる中点は原文を維持する。

### 2.2 時間当たりの単位

法令データ内で確認できた複合単位を固定辞書へ登録する。未知の組合せは推測せず原文を維持する。

- `立方メートル毎時` → `m³/時間`
- `立方メートル毎分` → `m³/分`
- `リットル毎分` → `L/分`
- `メートル毎秒` → `m/秒`
- `メートル毎秒毎秒` → `m/秒²`
- `ミリグレイ毎時` → `mGy/時間`
- `マイクログレイ毎時` → `μGy/時間`
- `マイクロシーベルト毎時` → `μSv/時間`

長い表現を短い表現より先に照合し、`メートル毎秒毎秒` が `メートル毎秒` と `毎秒` に分割されることを防ぐ。

`毎時十四立方メートル`のように時間語が数量・単位より前にある文章は語順を変更しない。既存規則による数値と単位の記号化だけを適用し、`毎時14m³`と表示する。

### 2.3 パーセントなど小数直後の単位

単独単位の誤変換防止条件は維持する。ただし、直前の数量判定に `〇` と `零` を含め、小数部がゼロで終わる場合も単位を変換できるようにする。

- `三・〇パーセント` → `3.0%`
- `〇・〇ミリグラム` → `0.0mg`

### 2.4 コピー

通常の `Cmd+C` / `Ctrl+C` は、ブラウザーで選択した画面表示文字列をプレーンテキストとしてコピーする。

- `二十・五パーセント`の表示を選択 → `20.5%`
- `立方メートル毎時`の表示を選択 → `m³/時間`
- 縦分数の表示を選択 → `7/10`

コピー処理だけを表示基準へ変更する。`data-original-text`、`data-source-start`、`data-source-end`は保持し、ハイライトや注釈で公式原文位置を復元できる状態を維持する。

## 3. 実装方針

### 3.1 小数変換

`legal-display-format.ts`の小数認識を、整数部一文字限定から、位取り文字を含む漢数字数量全体へ拡張する。

小数変換は次の順序で行う。

1. `・`の前後を一つの小数表現として認識する。
2. 整数部は既存の数量変換規則で算用数字化し、万・億は文字を残す。
3. 小数部は各漢数字を一桁ずつ算用数字へ置換する。
4. 原文全体を一つの `number` トークンとして保持する。

トークンの原文範囲は小数表現全体を指すため、ハイライト座標を壊さない。

### 3.2 単位変換

`legal-unit-dictionary.ts`へ確認済みの複合単位を明示的に追加する。辞書の長さ降順ソートと、未知の単位を原文維持する既存方針は変えない。

### 3.3 コピー処理

全文ビューのコピー境界で公式原文へ差し替えている処理を、選択範囲の表示文字列をコピーする処理へ変更する。選択範囲が法令本文外にある場合は処理しない。

原文座標へ戻す `getSelectionContext` はハイライト・注釈用として維持し、通常コピーからは使用しない。

## 4. データフロー

1. DBから公式原文を取得する。
2. `formatLegalText`が原文を表示トークンへ変換する。
3. レンダラーが表示文字と原文座標属性をDOMへ出力する。
4. 通常コピーはDOM上の表示文字列をクリップボードへ書き込む。
5. ハイライト・注釈は従来どおり原文座標へ逆変換する。

DB保存値およびAPIレスポンスの公式原文は変更しない。

## 5. エラー処理と安全策

- 小数として完全一致しない中点表現は変換しない。
- 小数部に十・百・千などの位取り文字がある不正または未知の表現は原文を維持する。
- 辞書にない複合単位は推測変換しない。
- コピー対象が空、折り畳まれている、または法令本文外の場合はブラウザー標準動作へ委ねる。
- 原文座標属性は削除・変更しない。

## 6. テスト方針

### 6.1 単体テスト

- 複数桁整数部を持つ小数が正しく変換される。
- 小数部の先頭・末尾ゼロが保持される。
- 小数直後の `%`、`mg`が変換される。
- `A・B`が変換されない。
- 確認済みの時間単位が固定辞書どおり変換される。
- 長い複合単位が優先される。
- 未知の単位は原文のままになる。

### 6.2 実画面テスト

- 対象条文で`20.5%`が表示される。
- 対象条文で`m³/時間`が表示される。
- 表セルでも同じ変換が適用される。
- 数値、単位、文章全体のコピー結果が画面表示と一致する。
- 原文座標属性が引き続き存在する。

## 7. 非対象

- DB内の公式原文の書換え
- すべての物理単位を推測する汎用単位パーサー
- コピー用の新しいボタンやメニュー
- ハイライト・注釈の保存形式変更
- 法令引用時に公式原文を取得する別機能の追加

## 8. 完了条件

- `二十・五パーセント`が本文・表で`20.5%`と表示される。
- 承認済み時間単位が固定辞書どおり表示される。
- 通常コピーで画面表示どおりのテキストを取得できる。
- 既存の原文座標、ハイライト、条文リンクが維持される。
- 単体テスト、型検査、対象実画面テストが成功する。
