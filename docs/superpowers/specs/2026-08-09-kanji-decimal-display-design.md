# 漢数字小数の表示変換 設計

## 目的

法令原文の漢数字小数を、横書き法令集の表記規則に合わせて算用数字の小数へ変換する。例として `三・〇` は `3.0`、`〇・〇〇三` は `0.003` と表示する。

## 表示仕様

- `〇零一二三四五六七八九` のいずれか1字、`・`、同じ数字集合の1字以上が連続する場合だけ小数とみなす。
- 整数部・小数部を桁ごとに `0`〜`9` へ変換し、`・` を `.` へ変換する。
- 本文と表の両方へ同じルールを適用する。
- `A・B`、人名・名称など数値でない中点は変更しない。
- 原文は変更せず、表示トークンの `sourceStart` と `sourceEnd` は小数原文全体の範囲を保持する。

## 採用設計

共通表示関数 `formatLegalText` の走査先頭で、漢数字シーケンスや通常文字へ分割する前に小数パターンを検出する。該当時は小数全体を `kind: "number"` の単一トークンへ変換する。

### 検討した代替案

1. 共通表示トークンで小数を認識する: 本文・表で統一でき、原文座標も保持できるため採用。
2. 表レンダラーだけで文字列置換する: 本文では未変換のままになり、座標管理も重複するため不採用。
3. DB取込時に原文を書き換える: e-Gov原文の保存原則に反するため不採用。

## 検証

- `三・〇 → 3.0`、`〇・〇〇三 → 0.003`、文中小数、通常の中点を単体テストする。
- 変換トークンが原文全体の座標範囲を保持することを確認する。
- 建築基準法施行令の実データで `三・〇` が `3.0` と表示されることをブラウザで確認する。
