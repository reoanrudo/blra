# 建築法令 Domain Reviewer — 役割定義と依頼条件

- 作成日: 2026-07-29
- 位置付け: S1 着手の**唯一のハードブロッカー**（設計書 ADR-016、ADR-024）
- 対応する未解決事項: O-9（人選と契約条件）

候補者への説明にそのまま使えるよう書いてある。

---

## なぜこの役割が必要か

BLRA の価値は「表示している条文が、指定した時点において正しい」という一点に全面的に依存する。誤った条文を自信を持って表示した瞬間に、このプロダクトの存在価値は失われる（設計書 §18）。

問題は、**この正しさを実装者が自己検証できない**ことである。AI を使っても同じである。

- 構造化した条文が原文と一致しているか
- 告示と法令の対応付けが妥当か
- 参照関係の抽出結果が実務上の読み方と合っているか
- 検索課題の「正解」が本当に正解か

これらは建築実務の知識を持つ人間にしか判定できない。実装者が兼任すると、**動くものは速くできるが、内容が誤ったまま Pilot に出る。**

したがって設計書 ADR-016 は、Domain Reviewer の外部確保を S1 着手の必須条件とし、実装者による兼任を禁じている。

## 依頼する作業

コードを読む必要はない。**判定と指摘だけをお願いする。**

| フェーズ | 作業内容 | 目安工数 |
|---|---|---|
| 着手前 | 対象テーマ（防火・避難）の妥当性確認。検索課題30件の正解セット確認 | 8〜12 時間 |
| S1〜S2 | 構造化結果の抽出精度確認、告示と法令の対応付け確認 | 月 4〜8 時間 |
| S2 | 引用解決の期待値確認（Golden Test） | 4〜6 時間 |
| Pilot | 成果の正確性検証（時点表示正確性 99% の判定） | 8〜12 時間 |

期間はおよそ 7〜8 か月、総計 60〜100 時間程度を見込む。フルタイムではない。

### 具体的にお願いする判定の例

- 「建築基準法35条の2について、2026年4月1日時点の本文はこれで正しいか」
- 「この告示は、法のこの条項の委任を受けたものか」
- 「『排煙設備が必要か』という調査で、確認すべき条文はこの5つで漏れがないか」
- 「この条文から、この告示への参照を張るのは実務上妥当か」

## 求める要件

### 必須

- 建築基準法の実務経験（設計、確認審査、または法令コンサルティング）
- 告示・技術的助言まで含めて根拠を辿った経験があること
- **誤りを誤りとして指摘できること**（遠慮されると役割が成立しない）

### 望ましい

- 一級建築士、建築基準適合判定資格者、またはこれに準じる資格
- 防火・避難分野の実務経験
- 確認申請の審査側または申請側での実務

### この役割に向かない人

- 実装や技術判断に関与したい方（役割の分離が崩れる）
- 「だいたい合っている」で通す方

## 契約条件の考え方

### 有償で契約する

**無償の善意に依存しない。** 最も削ってはならない工程が、最初に止まる。

時間単価契約または月額固定を想定する。専門性に見合う水準とし、値切らない。ここを安く上げると、確認が形骸化して意味を失う。

### 責任範囲を明確にする

契約書に明記する。

- Domain Reviewer は**確認・指摘を行う**。最終的なプロダクトの責任を負わない
- Domain Reviewer の確認は、**法的な適合性の保証ではない**
- 本サービスの利用者に対して、Domain Reviewer は責任を負わない

これは設計書 §10.4 の「`REVIEWED` は法的適合判定でも行政承認でもない」という原則と同じ考え方である。役割を明確にしないと、専門家が引き受けにくい。

### 機密保持

Pilot 参加組織の案件情報に触れる可能性がある。NDA を締結する。

## 人数

**1〜2名。** 1名でも成立するが、次の理由で2名が望ましい。

- 判断が分かれる論点で、単独の見解に依存しない
- 稼働できない期間があってもプロジェクトが止まらない

設計側（設計事務所）と審査側（確認検査機関・行政）から1名ずつ確保できると、視点の偏りを避けられる。

## 探し方

| 経路 | 備考 |
|---|---|
| 建築士事務所協会・建築士会 | 地域支部経由での紹介 |
| 指定確認検査機関のOB | 審査側の視点が得られる |
| U-1 インタビュー参加者 | **最有力。** 実務者調査で協力的だった方に打診する |
| 建築系の実務者コミュニティ | 勉強会・講習会の講師など |

U-1（実務者ヒアリング）と並行して進めると、候補者の実務レベルを見たうえで打診できる。**U-1 のクロージングで「試作ができたら使ってみていただけますか」と聞く際、反応の良い方が候補になる。**
