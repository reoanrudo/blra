# U-2 Baseline 計測プロトコル

Pilot 時の比較基準線を作る。設計書 §14.4 の North Star「有効条文到達時間の中央値短縮率」は、**ここで測った値を分母とする。** 測り方が揺れると Pilot の成否判定が揺れる。

---

## 計測の原則

1. **被験者が普段使っている手段でやってもらう。** 紙の法令集、e-Gov、既存サービス、社内資料、何でもよい。指定しない
2. **進行役は助言しない。** 詰まっていても待つ
3. **ストップウォッチを見せない。** 画面録画から後で計測する。計測されている感覚は行動を変える
4. **タスクは1件ずつ、区切って行う。** 前のタスクの調べ物を持ち越さない
5. 想定時間を超えたら打ち切る。**打ち切り自体がデータである**（「現行手段では時間内に終わらない」）

## 記録方法

- 画面録画（音声込み）。開始と終了の合図を口頭で入れる
- 進行役は手元で経路のメモだけ取る。時間は後から録画で測る

---

## タスク定義

3タスクとも、対象は S0 で構造化を実証済みの範囲（建築基準法・施行令・施行規則＋関連告示）から選んでいる。**MVP が扱える範囲で測らないと、Pilot と比較できない。**

各タスクは、被験者が実務で遭遇する形の設問にする。条番号を問いに含めない（それでは検索の課題にならない）。

### タスク1: 排煙設備の要否（告示依存が高い）

> 3階建て、延べ面積 600㎡ の物販店舗です。1階に窓のない事務室があります。この事務室に排煙設備が必要かどうか、根拠となる条文を示してください。

- 想定経路: 法35条 → 令126条の2 → 令126条の3 → 関連告示
- 打ち切り: 20分
- **このタスクは案B の影響を最も強く受ける。** 告示の現行全文が必要になる場面が実際に出るかを観察する

### タスク2: 防火区画の貫通部

> 準耐火構造の防火区画を給水管が貫通します。管の外径と材質について、遵守すべき基準の根拠条文を示してください。

- 想定経路: 令112条 → 令129条の2の4 → 告示（令和7年国交省告示第509号で改正済み）
- 打ち切り: 20分
- 直近に改正がある論点。**版の取り違えが起きるかを観察する**

### タスク3: 時点の特定（F-9 の制約に関わる）

> 2020年4月1日に確認申請を出した建物について、当時の建築基準法35条の2（内装制限）はどう書かれていましたか。現在の条文と違いますか。

- 想定経路: 過去版の入手手段があるか。なければ「分からない」で終わる
- 打ち切り: 10分
- **多くの被験者が現行手段では解けないと予想される。** 解けない場合、その事実と「実務でどうしているか」を聞く

## 正解セットの用意

各タスクの正解（到達すべき条文の集合）を**事前に作り、Domain Reviewer に確認してもらう。**

これは2つの用途を兼ねる。

1. U-2 の「見落とし」判定の基準
2. **U-3（検索課題30件と正解セット）の最初の3件**。設計書 §9.5 の Search Evaluation Harness にそのまま入る

Domain Reviewer が未確保の場合、正解セットは暫定とし、確保後に検証する。**暫定のまま Pilot の合格判定に使わない**（設計書 §9.5 の注記のとおり、正解セット1〜2件の誤りで Recall@10 の判定が反転しうる）。

## 集計

全被験者の実施後、タスクごとに次を出す。

| 指標 | 用途 |
|---|---|
| 有効条文到達時間の**中央値** | North Star の分母（§14.4）。平均でなく中央値を使う。少数の極端値に引きずられるため |
| 総所要時間の中央値 | 同上 |
| 見落とし率 | Pilot での「見落とし削減」の基準線 |
| 打ち切り率 | 現行手段の限界を示す |
| ツール切替回数の中央値 | 分散の程度を示す。設計書 §1.1 の課題の定量化 |

被験者が5名の場合、中央値は3番目の値である。**この規模で平均や標準偏差を語らない。** 数字が独り歩きする。
