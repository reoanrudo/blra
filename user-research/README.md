# U-1 / U-2 実務者調査 — 実施設計

- 作成日: 2026-07-29
- 目的: S0 完了後の**唯一の critical path risk**（ADR-024）を解消する
- 対象: 設計書 §15.3 の U-1〜U-3。Solo Track（§15.8.3）の規模で実施
- 根拠: 調査記録 第15章。ただし**同章は S0 実施前に書かれており、案B（ADR-023）と F-9 の制約が反映されていない**。本設計が優先する

---

## この調査で決めること

ADR-024 は U-1 を S1 着手の実質的な前提に格上げした。理由は次である。

S0 の結果、MVP が提供できるものと、できないものが確定した。

| | 内容 |
|---|---|
| **提供できる** | 法・令・規則の現行と履歴、時点指定、参照ナビ、案件別の根拠保存、第三者が再現できる Evidence Snapshot |
| **提供できない** | 告示の現行全文（案B・ADR-023）、2016年以前の条文（F-9）、全国の自治体条例 |

つまり**価値提案の重心が「網羅的な法令コーパス」から「調査ワークフローの道具」へ移った。**

この調査で答えを出すのは1点である。

> 建築実務者にとって、コストの中心は「条文を見つけること」か、「根拠をまとめて確信を持ち、他人へ引き渡すこと」か。

前者なら、告示の現行全文を出せない MVP は価値が薄い。案A の限定適用か案C（テーマ変更）へ戻る必要がある。
後者なら、案B のまま進んでよい。

## 設計上の要点

### 1. 制約を先に説明しない

**最も重要な設計判断である。**

「告示の現行全文が読めないツールに価値がありますか」と聞けば、ほぼ確実に「読めないと困る」と返る。人は提示された制約に対して反応を作るためである。これでは何も分からない。

したがってセッションは次の順序に固定する。

```
現状の困りごとを具体的な案件で語ってもらう
        ↓
実際に調査タスクをやってもらい、時間と経路を実測する
        ↓
ここで初めて制約を提示し、反応を見る
```

制約提示を最後に置くことで、前半の発言と観察が制約の影響を受けない。

### 2. 意見ではなく行動を測る

「どんな機能が欲しいですか」は聞かない。利用者は現行の制約を前提に解決策を語るため、要求仕様は発言ではなく観察から導く（調査記録 §15.9）。

U-2 のタスク実測（実際に調べてもらい、画面録画から時間を計測する）が、この調査の中心である。インタビューはその文脈を補うものと位置づける。

### 3. U-1 と U-2 を同一セッションで行う

Baseline 計測（U-2）は Pilot 時の比較対象になる。別日に分けると被験者の再確保コストが倍になり、Solo Track では回らない。90分1回で両方を取る。

## 実装者自身によるセルフテストとの関係

実装者は二級建築士で、老人ホーム規模の設計実務経験がある（ADR-025）。したがって次は**実装者が自力で行う**。外部participantを待たない。

- U-2 Baseline タスクの設計と正解セットの作成
- タスクが解ける形になっているか、想定経路を辿れるかの検証
- 実務語と法令語の対応表の初期作成

仮想の物件情報を使ったセルフテストは、この作業そのものである。参加者に当てる前にプロトコルを通しで試す意味もある。

**ただしセルフテストで埋まらないものが1つある。** 「他の実務者が対価を払うか」である。自分が痛いと感じる箇所は分かっても、それが市場の痛点かは n=1 では決まらない。U-1 の実務者接点が必要なのはこの一点のためであり、**正解セット作成のためではない。**

## 実施規模（Solo Track）

設計書 §15.9 のとおり、原案の 10名・3組織は集まらない前提で設定する。

| 項目 | 目標 | 最低 |
|---|---|---|
| 人数 | 8名 | **5名** |
| 組織数 | 3組織 | **2組織** |
| 役割の内訳 | 設計実務者 4〜5名、レビュー側（管理者・主任）2〜3名 | 各1名以上 |
| 1セッション | 90分 | — |

レビュー側を必ず含める。設計書 §2.1 は Researcher と Reviewer の両方を主対象としており、**仮説E（レビューは根拠の再構築になっている）は設計者だけに聞いても検証できない。**

## 倫理と機密（調査記録 §15.10）

建築案件には施主情報、未公開計画、住所、図面、行政相談内容が含まれる。次を必須とする。

- 事前同意と録画範囲の明示、録画停止をいつでも選択可能とすること
- 案件名・住所・企業名の匿名化
- 図面は必要最小限のみ取得
- 保存期間の明示と目的外利用の禁止
- **外部 AI サービスへ機密資料を送信しない**

同意書は初回セッション前に用意する。
