# 一級建築士法規過去問による要件学習

- 方針変更日: 2026-08-09
- 対象: 一級建築士「学科Ⅲ（法規）」令和3〜7年、計150問
- 目的: 外部参加者を集める U-1/U-2 を廃止し、公式過去問からユーザー課題と評価基準を作る
- 決定: ADR-031

## 方針

外部5名・2組織以上へのインタビューや所要時間計測を、開発の前提条件にしない。

代わりに、建築技術教育普及センターが公開する一級建築士「学科Ⅲ（法規）」の問題と
正答肢を一次資料として、次を学習する。

- 用途、規模、階数、構造、地域、工事種別、時点など、判断の入力条件
- 条文番号を知らない状態から使う検索語
- 法、令、規則、告示、他法令へ移動する経路
- ただし書、適用除外、緩和、経過措置の確認方法
- 複数法令を横断する設計者判断

## 実施単位

| 旧項目 | 新しい実施内容 | 完了条件 |
|---|---|---|
| U-1 実務者インタビュー | 令和3〜6年120問の課題分類 | 全選択肢から条件、派生論点、対象法令、複数の根拠経路を付与 |
| U-2 Baseline 計測 | 令和7年30問の未見ベンチマーク | 論点別の検索・根拠・例外・未収録と問題全体の統合判断を記録 |
| U-3 検索課題収集 | 過去問から検索課題へ変換 | 問題文・選択肢を転載せず、全選択肢をカバーする派生論点と正解セットを作成 |
| U-4 Design Partner | 年次ロールフォワード | 新年度問題を未見評価へ追加し、前年を学習セットへ移動 |

## 成果物

- 問題→全選択肢由来の派生論点→統合判断の階層型メタデータ
- 実務語・法令語・条件語の辞書
- 論点別の根拠条文セットと複数の法令間経路
- Search Evaluation Harness 用の学習120問・未見評価30問
- 問題・論点カテゴリ別の Recall@10、根拠到達率、例外確認率、未収録明示率、複合問題完了率

## 現在の実装状況

- 令和3〜7年150問のID、公式正答肢、法令基準日をマニフェスト化済み
- 学習120問と未見評価30問の分離、Recall@10・MRR等の評価器を実装済み
- 令和3年30問の正答主要論点を下書き登録済み。ただし全選択肢由来の論点と統合判断は未整備の
  部分データ
- 当時法令との突合を完了した検証済みデータは0/150問
